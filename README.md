## 📌 1. Présentation du projet

Ce projet consiste à réaliser une fleur artistique à l'aide du langage **Python** et de la bibliothèque **Turtle**.

Le programme permet à l'utilisateur de personnaliser son dessin en saisissant lui-même les informations suivantes :

- 🌸 Le nombre de pétales.
- 📏 La taille des pétales.
- 🎨 La première couleur.
- 🎨 La deuxième couleur.
- 🎨 La troisième couleur.

Le dessin est ensuite généré automatiquement en fonction des informations saisies.

## 🎨 2. Aperçu du dessin

```text
              🌸
          \   |   /
       🌸 \   |   / 🌸
          \  |  /
       ---- 🌼 ----
          /  |  \
       🌸 /   |   \ 🌸
          /   |   \
              |
```

Chaque utilisateur peut créer une fleur différente en modifiant les paramètres.

## 🖥️ 5. Utilisation du programme

Au démarrage, le programme demande à l'utilisateur de saisir ses informations.

Exemple :

```text
Combien de pétales voulez-vous ? : 12
Quelle taille pour les pétales ? : 80

Première couleur : red
Deuxième couleur : yellow
Troisième couleur : blue
```

Après la saisie, la fenêtre Turtle affiche automatiquement la fleur.

## 🧠 6. Notions de programmation utilisées

Ce projet permet de mettre en pratique plusieurs notions fondamentales de Python :

- **Les variables :** pour stocker les données saisies.
- **input() :** pour permettre à l'utilisateur d'entrer ses informations.
- **int() :** pour convertir une saisie en nombre entier.
- **Les conditions if / elif / else :** pour choisir les couleurs.
- **La boucle for :** pour répéter le dessin des pétales.
- **Les fonctions :** pour regrouper les instructions permettant de dessiner un pétale.
- **La bibliothèque Turtle :** pour réaliser le dessin.

### Calcul de la rotation

Le programme utilise la formule :

`360 / nombre`

Elle permet de répartir les pétales autour du centre de la fleur.

Exemples :

| Nombre de pétales | Angle de rotation |
|---:|---:|
| 6 | 60° |
| 12 | 30° |
| 20 | 18° |
| 24 | 15° |
